# Personal Portfolio Page

A personal portfolio website built during my Web Development
coursework at TAMK, showcasing basic frontend fundamentals.

🔗 **Live demo:** https://yagmur-ero.github.io/yagmur-portfolio-page/

## Features
- Responsive layout with Flexbox
- Navigation between home and projects pages
- Basic personal branding (profile section, project showcase)

## Tech Stack
HTML5, CSS3, JavaScript, GitHub Pages

## Files
- `index.html` — home page (includes small JavaScript for the
  active navigation link and the CV button)
- `projects.html` — projects showcase page
- `style.css` — styling and layout

## Note
Frontend is not my primary focus (I'm more interested in
backend part), but this project reflects my
foundational web development skills.
